# prompts — 提示词收藏

我常用的提示词收藏库。**只收正在用的，不常用就删**——这是工具箱，不是档案馆。

## 收录规则

- **一条一文件**，目录即收录清单（同 `skills/`）：文件在即收录，删文件即下架。
- 文件名英文 kebab-case（如 `weekly-report.md`），文件内第一行写中文标题。
- **只收自己实际在用、验证有效的**；不常用即删，不让收藏夹吃灰。
- 外部来源的提示词直接入库（纯文本、无执行风险，豁免于"第三方内容不入库"铁律），但必须标一行出处。
- 刻意保持小规模：平铺、无分类子目录、无索引页。规模失控时先删后加，实在超量再考虑重构。

## 条目模板

```
# <名称>

> 用途：<什么时候用它，一两行>
> 来源：<url 或出处>          ← 仅外部来源的条目需要

---

<提示词正文>
```

约定：**分隔线以下 = 正文**。复制时分隔线以下整段拿走，不会误带说明；正文不包 code fence，避免嵌套转义。
